Each page follows a common pattern: simple explanation, problem, core mechanism, information flow, strengths, limitations and comparison. Use `templates/architecture-page-template.md` when adding a new architecture.

The key question is never only “which architecture is best?” Instead ask: best for which modality, sequence length, latency target, memory budget, hardware, scaling strategy and learning objective?
